# Uncharted: The Nathan Drake Collection — Guía comunitaria para PC

**Por TobyCoderExe | Español**

Guía comunitaria para principiantes que documenta la experiencia de ejecutar *Uncharted: The Nathan Drake Collection* en Windows mediante un port comunitario.

### Proyecto original

Esta guía complementa, pero no sustituye, la documentación del proyecto original:

- [Supermedo/uncharted_pc](https://github.com/Supermedo/uncharted_pc/releases/tag/v0.3.3)

### ¿Qué encontrarás aquí?

- Preparación y organización de archivos.
- Herramientas utilizadas.
- Registro de errores y posibles soluciones.
- Pruebas de rendimiento y configuración.

### Estado de la guía

Esta documentación se basa en pruebas personales. Las causas de los errores y las soluciones propuestas se marcarán como pendientes hasta que puedan verificarse.

### Reglas importantes

- No se distribuyen archivos del juego ni contenido protegido por derechos de autor.
- Utiliza únicamente archivos que tengas derecho a utilizar.
- Consulta los requisitos y las instrucciones de la versión actual del port.
- No consideres una hipótesis como una solución confirmada.
